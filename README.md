# Esteticista Loyara Lobo

Aplicativo web/PWA da Esteticista Loyara Lobo.

## Funções
- Cadastro de clientes
- Cadastro e edição de procedimentos
- Preço, custo e lucro mínimo por sessão
- Montagem de pacotes com desconto seguro
- Bloqueio de pacote abaixo do custo + lucro mínimo
- Controle de sessões
- Agenda
- Registro de pagamentos
- Financeiro
- Lucro realizado por procedimento
- Instalação na tela inicial do celular

## Publicação
Os arquivos estão prontos para GitHub Pages a partir da raiz da branch main.
